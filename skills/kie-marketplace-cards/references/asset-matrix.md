# Marketplace asset matrix

Choose only assets that support the listing story.

| Asset | Purpose | Generation boundary |
| --- | --- | --- |
| Main image | Clear product recognition | Preserve exact product/count; follow current platform background rules. |
| Infographic | Explain one or two verified benefits | Add all text and measurement lines locally. |
| Multi-angle | Show form and construction | Maintain geometry and packaging identity. |
| Detail shot | Prove material or feature | Do not hallucinate texture or mechanism. |
| Lifestyle | Show context and scale | Mark illustrative contexts where needed. |
| What's in the box | Confirm included contents | Use supplied inventory only. |
| A+ hero | Establish brand/product story | Compose exact brand copy locally. |
| Pain points | Frame a buyer problem | Avoid fear, diagnosis, and unverified outcomes. |
| Features | Explain mechanisms | Tie every statement to supplied evidence. |
| Ingredients/materials | Show composition | Use exact names and regulated wording. |
| Efficacy/results | Present supported evidence | Require substantiation and disclaimers. |
| How to use | Show ordered steps | Check safety and supplied instructions. |
| Endorsement | Present an authentic source | Require explicit permission and exact quote. |

Suggested scopes: `main`, `product-images` (main plus five), `aplus` (main plus seven), or `full-set`. Treat these as planning shorthand, not platform certification.
