# Kie Avatar

Start with `$kie-grilling`, then use `$kie-identity` for any recurring or real-person likeness. Confirm authority for both face and voice, intended audience/use, and whether generated-media disclosure is required. Never imply a provider-scoped character ID or local bundle is a portable trained Soul identity.

Inspect current routes rather than assuming a specific provider:

```bash
kie-pp-cli media capability list --capability kie-avatar --agent
kie-pp-cli media capability show <model-id> --agent
kie-pp-cli models show <model-id> --agent
```

Prepare approved portrait/reference media, script, pronunciation, language, voice/audio, framing, gesture, and delivery. Validate exact input with `models validate`. Where the director supports the route, use its mandatory still and optional complete-shot proof gates; otherwise manually show the lowest-cost supported preview artifact before a final render.

Every preview, lip-sync, voice, avatar, regeneration, and final render is a separate paid action. State its model/settings and cost uncertainty immediately before asking for an explicit yes. Never reuse that answer for another call. Deliver the artifact with provider task ID, references/consent provenance, disclosure notes, and identity-match limitations.
