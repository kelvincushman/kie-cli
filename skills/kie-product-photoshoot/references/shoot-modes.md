# Shoot modes

| Mode | Brief emphasis |
| --- | --- |
| `product_shot` | Controlled studio surface, light, shadow, camera, clean fidelity. |
| `lifestyle_scene` | Authentic context, audience, scale, and interaction. |
| `closeup_product_with_person` | Product feature plus consented person detail. |
| `moodboard_pin` | One visual direction, materials, palette, and atmosphere. |
| `hero_banner` | Clear negative space, crop safety, and landing-page hierarchy. |
| `social_carousel` | Consistent multi-card narrative and crop system. |
| `ad_creative_pack` | Distinct hooks using the same locked product truth. |
| `virtual_model_tryout` | Garment/accessory placement with illustrative-fit caveat. |
| `conceptual_product` | Deliberately surreal or speculative treatment, clearly labeled. |
| `restyle` | Preserve product; change only environment, light, palette, or camera language. |

For a series, lock focal length family, light direction, contrast, palette, surface language, grain, and shadow character. Change one major variable per iteration so failures remain diagnosable.
